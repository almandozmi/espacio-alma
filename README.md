Centraliza toda la información clave del estudio, incluyendo su propuesta, horarios, valores y canales de contacto, ofreciendo una experiencia clara y directa para facilitar el proceso de inscripción.

```
.
├── .github/
│   ├── workflows/ci.yml          # Revisiones automáticas de cada cambio
│   └── dependabot.yml            # Actualización de las acciones de GitHub
├── apps-script/
│   └── transfer-requests.gs      # Recibe el formulario
├── site/                         
│   ├── index.html                # Página principal
│   ├── terminos-y-condiciones.html
│   ├── _headers                  # Encabezados de seguridad
│   ├── css/                      # Estilos de la página
│   ├── js/                       # Menú y formulario de transferencia
│   ├── fonts/                    # Fuentes
│   └── images/
│       ├── logos/                # Logos
│       └── photos/               # Fotos
└── tests/
    └── format.test.js            # Pruebas de los campos del formulario
```
